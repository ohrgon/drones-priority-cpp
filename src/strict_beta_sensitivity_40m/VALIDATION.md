# 검증 기록과 범위

## 수행한 로컬 검사

- 원래 NumPy 환경 코드로 17개 단위·통합 테스트 통과 (`validation/local_tests.log`).
- 최초 방문순서·도착방향 보존, 시간 비증가, 실패 경로 보존, 원본 내용·수정시각 보존.
- Raw 저장 직후 후처리를 중단해도 재개 시 원래 Raw를 재사용하고 추론을 반복하지 않는지 검사.
- 완료 경로 재개에서 연결 개선 반복 없음, 손상 cache를 miss로 무시하지 않고 거부하는지 검사.
- 세 β의 실제 별도 CPU 프로세스에서 저장 Raw 재사용 → 연결 개선 실행 확인(테스트용 지도, 모델 추론 없음).
- 세 β 공통 성공집합, 실패 분모, PARTIAL 표기, ZIP CRC 검사.
- 업로드된 실제 Strict β=0·40M Validation180 CSV의 ID/hash/초기조건/timestep/cost/성과 수치를 검산.
- 원래 `run_strict_50m.py`와 공통 refinement 엔진의 byte identity 확인.
- 실제 업로드 plan/registry/manifest를 사용하는 위치 탐색 검사 추가 수행. 이 검사는 모델 파일 내용 해시를 테스트에서만 대체하고 map 파일은 존재 확인용 임시 파일을 사용한 **메타데이터 연결 검사**임. 실제 weight 추론 검사로 세지 않음.

## 수행하지 않은 것

- 실제 사용자 서버의 40M 세 checkpoint를 이 컨테이너에서 로드하지 않았음.
- 실제 Validation180 × 세 β의 전체 경로 추론·연결 개선은 아직 이 패키지로 수행하지 않았음.
- 새 학습, Test/OSM 평가, COST1 경로 복구, 전체 논문 문서 수정은 이 패키지 범위 아님.

소스와 이미 보고된 Raw 값은 원자료에 근거하되, 아직 실행하지 않은 Refined 결과는 생성·예측하지 않음.
